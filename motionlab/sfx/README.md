# Pack de bruitages MotionLab

58 bruitages faits pour tes vidéos, rangés par usage. Tous ont été créés pour MotionLab : tu peux les utiliser dans
toutes tes vidéos, perso ou pour des clients, sans rien citer. Seule limite : pas de revente du pack tel quel.

Écoute-les tous d'un coup : **_preview.mp3** (dans l'ordre des dossiers ci-dessous).

| Dossier | Quand l'utiliser |
|---|---|
| `whoosh/` | Les 3 ou 4 plus grands mouvements de la vidéo, **pas plus** |
| `interface/` | Toutes les autres transitions : petits swish, pop, blip, tic, très bas |
| `click/` | Une souris ou un doigt qui clique, à chaque fois |
| `counter/` | Un nombre qui défile ou compte, sous toute la durée du défilement |
| `keyboard/` | Un texte qui se tape à l'écran |
| `money/` | De l'argent qui apparaît |
| `sparkle/` | Un élément qui brille : **un seul** son de ce dossier par vidéo |
| `notification/` | Une notification, un message qui arrive, une validation |
| `error/` | Une erreur, un refus |
| `impact/` | Un impact, un tampon, un objet qui tombe |
| `riser/` | Une montée de tension juste avant une révélation |
| `scan/` | Un scan, une analyse, un balayage |

## Comment t'en servir

- **Avec l'agent.** Quand il te demande « avec son ou sans ? », réponds par exemple : « Avec son, utilise le pack
  `sfx/` et suis les règles de dosage du guide. » Ajoute ta musique si tu en as une.
- **À la main.** Dans l'éditeur, les sons du pack sont dans la bibliothèque (groupe Sons) : glisse-les sur une piste,
  cale leur pic sur l'image, règle le volume.

Tous les fichiers sont au même niveau de crête. Dans une vidéo, garde-les **bas** : ils doivent se fondre sous la voix.
Si tu les remarques comme des « sons », ils sont trop forts.
