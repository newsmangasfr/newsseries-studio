# Les effets prêts

`apercu.mp4` montre les neuf effets que l’agent peut utiliser dans tes vidéos : un compteur qui roule, un texte qui
se décode, une carte au bord lumineux, un mot qui part en poussière, une image qui arrive en mosaïque, un radar, une
sphère qui « réfléchit », une carte en verre et une courbe qui se dessine.

Tu n’as rien à faire : l’agent les choisit quand ils servent une phrase. Tu peux aussi en demander un : « sur le
chiffre, fais rouler les chiffres », « fais apparaître le prompt comme s’il se décodait ».
