# Style 02 · Studio

Noir profond, mot actif blanc, mots dits en gris, mot clé dans un cadre bleu avec poignées. Les objets sont rendus de façon réaliste, avec une lumière dorée. C’est le look d’origine du format.

**Pour quels sujets :** Science, tech, « comment ça marche », tout sujet qui s’explique avec un objet du quotidien.

**Fonds :** surtout sombre.

**Pour l’utiliser :** dis à ton agent « style 02 » ou « je veux le style Studio ».

Regarde `apercu.mp4` dans ce dossier pour le voir bouger.

Le style règle les sous-titres, les couleurs, le fond et le bandeau du haut. `direction.md` dit à l’agent comment
dessiner les scènes dans ce style ; la méthode (une vraie chose par phrase, qui bouge sur son mot) reste la même.
